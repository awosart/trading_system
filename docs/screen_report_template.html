Выход скрина — гипотезы, а не свидетельства. Каждое число здесь получено внутри выборки: один период, параметры из файла стратегии, без фолдов, без подбора, без нулевых процессов. Хорошая строка означает ровно одно — «эту стратегию стоит прогнать через walk-forward на holdout», и никогда «эта стратегия работает».

Кросс-секционный z не снимает смещение, общее для всех стратегий на рынке. z стандартизует стратегию по распределению остальных стратегий на том же инструменте — это убирает инструмент-специфичный уровень и разброс, но если все стратегии на этом рынке длинные, а рынок рос, вся кросс-секция сдвинута, и z этого не заметит. Верхний дециль z — не свидетельство эджа. Подтверждающее сравнение — перцентиль против перестановочного и синтетического ноля этого инструмента, и оно на holdout, а не здесь. {% if report.trials %}
