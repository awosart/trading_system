# trading_system

Модульная торговая система. Стратегия не управляет деньгами — она отдаёт сигнал
с оценкой качества; размер позиции, стоп и допуск к торговле решают отдельные
модули. Полный контекст архитектуры и принятых решений — в `CLAUDE.md`.

## Карта модулей

В порядке потока данных: Market Data → Features → Regime → Strategy Selector →
Entry Engine → Signal → Risk Engine → Prop Guard → Execution → Portfolio →
Analytics.

| Модуль | Отвечает за |
|---|---|
| `core/` | Общие типы, конфиг, исключения, логирование, спецификация инструмента — на них опирается всё остальное |
| `data/` | Загрузка, валидация, хранение (DuckDB/Parquet), ресемплинг и торговые сессии рыночных данных |
| `features/` | Индикаторы и паттерны: векторный и инкрементальный расчёт, обязаны совпадать |
| `regime/` | Классификация режима рынка (тренд/range/волатильность) — пока не реализован |
| `strategies/` | Декларативная схема стратегии (`StrategySpec`) и её семантическая валидация |
| `entry/` | Entry Engine: распознаёт сетап на закрытом баре и оценивает его качеством, направлением и уровнем инвалидации |
| `exit/` | Exit Engine: ведёт уже открытую позицию — стоп, тейки, трейлинг; независим от Entry |
| `risk/` | Risk Engine: сайзинг позиции, портфельные лимиты, circuit breakers — знает только Signal и состояние счёта |
| `prop/` | Prop Guard: последний слой хардовых лимитов с правом veto — пока не реализован |
| `execution/` | Модель издержек и исполнения: спред, проскальзывание, комиссия, своп |
| `backtest/` | Событийный цикл бэктеста и портфель: мерж баров без lookahead, equity curve, оркестрация всех слоёв выше |
| `analytics/` | Отчётность и метрики по результатам прогона — пока не реализован |
| `news/`, `volume/` | Вспомогательные фиды (новостной календарь, объём) — пока не реализованы |
| `ui/` | Streamlit-интерфейс — в конце, пока не реализован |
| `cli.py` | Command-line точка входа (typer) |

## Установка и запуск

```bash
make install   # venv + зависимости
make lint      # ruff check + format --check
make typecheck # mypy --strict
make test      # pytest
make bench     # тесты производительности (деселектятся из `make test`)
make all       # lint + typecheck + test
```
